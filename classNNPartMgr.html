Detailed Description

template<typename Gnl, typename GainMgr, typename ConstrMgr>
class NNPartMgr< Gnl, GainMgr, ConstrMgr >

No-Nonsense Partitioning Algorithm Manager.

NNPartMgr reuses the shared FM algorithm skeleton from PartMgrBase (Template Method pattern: init/legalize/optimize) and overrides only the single-pass behaviour: unlike FM it is a pure greedy local search that stops at the first non-positive-gain move (no look-ahead / snapshot / rollback) and never locks a moved vertex. The gain-computation and constraint-validation strategies remain injected as template parameters.

Performs a single pass of the No-Nonsense optimization algorithm.

Pure greedy local search: repeatedly takes the highest-gain move from the gain buckets while its gain is strictly positive, and stops at the first non-positive-gain move. It performs no snapshotting/rollback and does not lock moved vertices.
