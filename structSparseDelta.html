Detailed Description

template<typename Node>
struct SparseDelta< Node >

One non-zero gain-key change produced by a general-net move.

The general-net kernel emits only the (vertex, target partition, delta) triples that actually change, so the manager applies them directly instead of scanning a dense degree x num_parts matrix.
